workspace-profiles

Named workspace profiles for Hyprland. Each profile owns its own browser data dir, mako rules, waybar layout, and SUPER+1..5 slots. Switch contexts with one keystroke.

One profile per context

Keep work and personal cleanly separated — or spin up a fresh profile per client. Every part of your desktop respects the active profile.

🌐

Per-profile browser

Each profile has its own Chromium user-data-dir. Link clicks anywhere on the system route through a shim that opens the active profile's browser — logged-in to the right account, with the right cookies.

🔔

Per-profile notifications

Mako rules switch with the profile. Mute the work channels on weekends. Hide personal Slack on Monday morning. Your choice, your rules.

📋

Named SUPER+1..5 slots

Replace numeric workspaces with named slots. SUPER+1 on profile work is your editor; on personal it's your inbox. Same keystroke, different intent.

🔄

Cycle profiles

SUPER+CTRL+TAB cycles. SUPER+CTRL+1..9 jumps to a specific profile. SUPER+CTRL+SHIFT+N sends the focused window to profile N.

💬

Waybar widget

A persistent module shows the active profile and slot. Updates instantly on switch. Sidecar CSS so it doesn't fight your theme.

⚙

Sync daemon

Background process keeps active-profile state in sync with focus changes — even when a mako click or external app jumps you to a workspace the controller didn't trigger.

🔥

Native Omarchy menu

Adds a Workspace Profiles submenu to omarchy-menu. Switch, edit, or disable from the same launcher you already know.

✓

Idempotent setup

Run omarchy-setup-workspace-profiles as many times as you want. Refreshes binds and templates. Never clobbers your profile config.

📥

One AUR package

yay -S omarchy-workspace-profiles. No build step, no manual file shuffling. MIT licensed, 0.07 MiB installed.

Three commands to a working setup

Idempotent throughout. Re-run safely whenever you want to refresh.

1

Install

One package from the AUR pulls the four scripts and five config templates: yay -S omarchy-workspace-profiles.

2

Setup

Run omarchy-setup-workspace-profiles once. Registers the default-browser shim, hypr binds, mako include, and waybar widget. Seeds a single default profile.

3

Use

Cycle, switch, or move with the keybindings below. Edit ~/.config/omarchy/workspace-profiles.conf to add profiles — everything else updates automatically.

Keybindings cheat sheet

Numeric workspaces are remapped to the active profile's slots. Four-finger combinations let you jump across profiles.

~/.config/hypr/workspace-profiles.conf
SUPER + 1..5
Focus slot N of the active profile
SUPER + SHIFT + 1..5
Move focused window to slot N (follow)
SUPER + SHIFT + ALT + 1..5
Move focused window to slot N (silent)
SUPER + TAB
Cycle to next slot in active profile
SUPER + SHIFT + TAB
Cycle to previous slot in active profile
SUPER + CTRL + 1..9
Switch to profile N
SUPER + CTRL + TAB
Cycle to next profile
SUPER + CTRL + SHIFT + 1..9
Send focused window to profile N (stay put)

Profiles as config

Define profiles, slot names, and per-profile browser data dirs in one file. Run omarchy-workspace-profile reload after editing.

~/.config/omarchy/workspace-profiles.conf
# Each [profile] block defines slot names and a Chromium data dir.
# SUPER+1..5 always maps to slots 1..5 of the active profile.

[profile:work]
browser_dir = ~/.config/chromium-work
slots       = editor, terminal, browser, slack, mail

[profile:personal]
browser_dir = ~/.config/chromium-personal
slots       = browser, chat, music, notes, scratch

[profile:client-acme]
browser_dir = ~/.config/chromium-acme
slots       = code, repl, docs, jira, calls

[defaults]
active      = work
cycle_order = work, personal, client-acme
